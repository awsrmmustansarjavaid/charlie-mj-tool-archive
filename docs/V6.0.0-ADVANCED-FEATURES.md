# Charlie MJ Tool Archive v6.0.1 — Advanced Features & Operations

## Upgrade contract

v6.0.1 is a corrective, additive database release built on the supplied v5.0.0 extension and the earlier v6 work. Existing Manifest V3 behavior, Local and Remote libraries, GitHub synchronization, editor, favorites, search, legacy import/export, bookmark import, CSV/HTML exports, diagnostics and settings remain available. New database writes use IndexedDB; `localLibrary` remains mirrored for v5 compatibility and the existing service worker.

## New modules

| Module | Responsibility |
|---|---|
| `src/database-engine.js` | IndexedDB persistence, transactional collection writes, independent category collections |
| `src/advanced.js` | Hierarchy, stable IDs, smart labels, search scoring, duplicate similarity, collections and JSON category operations |
| `src/zip-manager.js` | ZIP creation and reading for portable category database backups |
| `src/background.js` additions | Chrome Omnibox provider using the `cmj` keyword |
| `src/dashboard.js` additions | Database Manager, category JSON import/export, folder/ZIP workflows and Command Center |

## Independent database model

IndexedDB database: `CharlieMJToolArchiveDB`.

- `categories`: immutable UUID category/subcategory nodes.
- `categoryCollections`: one independent logical collection per category/subcategory. A tool is stored in exactly one leaf collection, avoiding duplicate copies in parent collections.
- `collections`: user-created smart collection metadata referencing tool IDs.
- `meta`: schema and initialization marker.

The legacy `chrome.storage.local.localLibrary` value remains a compatibility mirror. On first startup, v5 records are migrated into IndexedDB without removing the old array. Later startup reads the initialized IndexedDB records and keeps the mirror updated for older features and background integrations.

## Actual portable JSON file layout

The project now includes a split seed database under `data/database/`:

```text
data/database/
  database-config.json
  categories-index.json
  categories/<category>.json
  subcategories/<parent>/<subcategory>.json
  backup-manifest.json
```

The included seed split contains 71 category JSON files for the 330 records in the supplied default library. Categories created later receive their own IndexedDB collection and can be exported as individual JSON files. A ZIP export contains one JSON file for every category and subcategory, using nested folder paths for subcategories.

**Chrome platform limitation:** an installed extension cannot silently create or rewrite arbitrary JSON files inside its own installation folder. IndexedDB is therefore the writable runtime database; JSON files are generated as user-initiated downloads or ZIP archives. The packaged `data/database/` files are seed/portable files, not live writable files.

## Category management

The Database Manager supports category creation, nested subcategory creation, rename, delete with a move-or-delete choice for affected records, drag/drop re-parenting, tool counts, category selection, moving tools, individual JSON export and category restore. Parent IDs remain stable when names change; human-readable display IDs are regenerated from the hierarchy.

## Import/export

- Legacy v5 JSON import remains supported.
- Multiple JSON files can be imported together with a preview and exact-duplicate check.
- A selected category can be exported to JSON and restored in merge or replace mode.
- Folder import accepts a user-selected folder of JSON files.
- ZIP export includes a config, category index, independent JSON collection files, collections metadata, legacy library compatibility export and manifest.
- ZIP import accepts stored and deflated ZIP entries.
- Full JSON backup remains available for compatibility.

## Search, Omnibox and duplicates

Smart search ranks exact names, name prefixes, domains, URLs, labels, categories, tags/aliases and descriptions. Chrome Omnibox is activated with `cmj` followed by Space or Tab; extensions cannot intercept every normal address-bar keystroke. Exact canonical URL duplicates are blocked; similar URLs are advisory and do not automatically reject different paths or query parameters.

## Existing features retained

The extension continues to support Local Default Library, Remote GitHub Library, Unified Library, source badges, GitHub sync, local copies, favorites, recently used, add/edit/delete, tags, notes, bookmark import, legacy JSON import/export, CSV export, HTML export, backup/restore, library comparison, diagnostics and manual website health checks.

## Scope notes

Some advanced roadmap items in the supplied plan remain future work rather than completed v6.0.1 features: full module-by-module enable/disable settings, automatic metadata extraction and category suggestions on every visited website, scheduled health checks, revision restore UI, detailed analytics dashboards, encrypted storage, cloud sync and AI-powered categorization. They are not represented as complete in this release.
