SMART LIBRARY CONTROL CENTER

Settings & Library Tools

📚 Two Default Libraries

The packaged data/default-tools.json is the Local Default Library. GitHub data/default-tools.json is the Remote Library. Both are kept independently and displayed together through the unified library.

☁ GitHub Library Sync

Checking GitHub sync status…

The extension checks your public GitHub data/default-tools.json automatically. New tools are added; local favorites, notes and usage history are preserved. Automatic sync runs periodically while Chrome is active.

🧹 Library Health & Cleanup

💾 Backup & Export

Backups include your local notes, favorites, categories and usage data. HTML export is self-contained and works offline.

🔄 Remote Changes & Safety

Remote updates are reviewed through the comparison view. Remote deletion never automatically deletes your local library. Remote-only tools remain remote; use Create Local Copy when you want to customize or favorite one locally.

⚙ Data Model

The live library is stored in Chrome local storage. default-tools.json is the bundled/GitHub seed snapshot, not the live database. Use JSON/HTML export when you want to move or publish your library.

Shortcuts: Ctrl + Shift + L opens the archive · Ctrl + K focuses search.
